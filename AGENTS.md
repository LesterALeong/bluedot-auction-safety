# BlueDot auction research

Use the project skills in [.agents/skills](.agents/skills) for paired experiment design, model run audits, offline decision replay, and research reporting. The [100 improvements](docs/research-improvements.md) define the checks for each skill. The matching read-only reviewers live in [.codex/agents](.codex/agents).

The files under `results/` are frozen study evidence. Replay them before using figures. A new experiment gets a new freeze and evidence directory. Keep scripted outcomes, recorded model observations, and planned buyer experiments visibly distinct. The BlueDot submission stays on hold until the user explicitly releases it.
