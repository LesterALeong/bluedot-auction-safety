# Report safety research

Use [checks 076–100 and the claim and transfer records](../../../docs/research-improvements.md#076100--report-and-transfer-findings). For a current evidence-backed draft, run `python -S -B research_toolkit.py check-in` from this checkout. Compare with the last check-in if it is available.

- Open with the buyer’s decision and the obstacle. Define the auction, the role of each model, and what the simulated credits buy. Explain where a prompt changes the proposed action and where the simulator controls commitment.
- Attach evidence and denominators to claims. Distinguish recorded measurements, deterministic policy replays, illustrations, and plans. Include relevant unresolved calls, pairing limits, and synthetic scope.
- Prefer an editable quote chart, approval decision tree, time-aligned replay, or baseline-versus-rule flow where each helps answer a question. Inspect the rendered deck and underlying chart values when available. Report missing source access if a native chart check is impossible. Have `research_claim_editor` cold-read the relevant artifact when clarity or provenance matters.
- For a transfer brief, name the reusable event fields, adapter assumptions, actor visibility, commitment rule, independent oracle, and welfare measure. Keep recipient-specific participation or validation conditional on evidence. Use public or independently shareable synthetic material.

Return the requested local draft or review and preserve the BlueDot submission hold. Publishing, form submission, and sharing require their own authorization.
